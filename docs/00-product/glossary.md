# Purpose

This glossary establishes the official terminology used throughout the platform.

Every business document, architecture document, API specification, database schema, source code, and user interface should use these definitions consistently.

When multiple words could describe the same concept, this glossary defines the preferred term.

---

# Business Terminology

## Platform

The complete cloud-native ecosystem that provides business software, custom software development, customer management, billing, and related services.

The platform contains multiple products and platform services.

---

## Product

An independently developed SaaS application offered through the platform.

Examples:

* Ticket Management
* CRM
* Inventory Management
* HRMS

Products are subscribable business applications.
